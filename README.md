# 🎯 파이썬 퀴즈 게임

## 📖 프로젝트 개요
객체지향(OOP)으로 만든 콘솔 기반 퀴즈 게임입니다.
사용자는 4지선다 퀴즈를 풀고, 직접 퀴즈를 추가·삭제할 수 있으며,
최고 점수가 자동으로 저장됩니다.
파이썬 기초 문법과 클래스, 파일 입출력(JSON)을 연습하기 위해 만들었습니다.

## 🧠 퀴즈 주제와 선정 이유
- **주제**: 기초 상식 (지리, 과학, 생활 상식 등)
- **선정 이유**: 특정 분야 지식이 없어도 누구나 부담 없이 풀 수 있고,
  남녀노소 쉽게 즐길 수 있는 주제라서 선택했습니다.

## ▶️ 실행 방법
1. 파이썬이 설치되어 있어야 합니다. (Python 3 권장)
2. 터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력합니다.

```bash
python quiz.py
기능 목록
번호	기능	설명
1	퀴즈 시작	저장된 퀴즈를 순서대로 풀고 점수를 계산합니다.
2	퀴즈 추가	문제·선택지·정답을 입력해 새 퀴즈를 등록합니다.
3	퀴즈 삭제	등록된 퀴즈를 골라서 삭제합니다.
4	퀴즈 목록	현재 저장된 퀴즈 목록을 보여줍니다.
5	최고 점수	지금까지의 최고 점수를 확인합니다.
6	종료	게임을 종료합니다.
잘못된 입력(문자, 공백, 범위 밖 숫자)은 안전하게 걸러냅니다.
Ctrl + C 를 눌러도 프로그램이 안전하게 종료됩니다.

파일 구조
quiz-game
├── quiz.py        # 메인 프로그램 (게임 실행 코드)
├── state.json     # 퀴즈 데이터 + 최고 점수 저장 파일 (자동 생성)
└── README.md      # 프로젝트 설명 문서
🗂️ 데이터 파일 설명 (state.json)
경로: 프로젝트 폴더 안 (quiz.py와 같은 위치)
역할: 퀴즈 목록과 최고 점수를 저장합니다.
프로그램을 껐다 켜도 데이터가 유지됩니다.
파일이 없으면 기본 퀴즈로 시작하며, 저장 시 자동 생성됩니다.
스키마(구조):
json
{
  "quizzes": [
    {
      "question": "대한민국의 수도는?",
      "choices": ["부산", "서울", "인천", "대구"],
      "answer": 2
    }
  ],
  "best_score": 5
}
키	자료형	설명
quizzes	리스트	퀴즈 여러 개를 담는 목록
question	문자열	문제 내용
choices	리스트(문자열 4개)	4지선다 선택지
answer	정수(1~4)	정답 번호
best_score	정수 또는 null	최고 점수 (없으면 null)
